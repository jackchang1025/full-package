## 三、Phase 0 — 开启开发者选项（华为/荣耀专用路径）

### 3.1 打开开发者选项页面 — 4 个 ComponentName 链式尝试

**文件**: `C0358a0.java:1077-1106` (OpenDevelopmentDelegate) 和 `C0360a2.java:4652-4693` (SystemOptimizeManager)

两个文件中有**完全相同的逻辑**（代码复制），确保两条调用路径都能正确处理华为：

```java
// 品牌匹配: hashCode 优化
int hash = brand.toLowerCase().hashCode();
if (hash == -1206476313 ? brand.equals("huawei") 
    : hash == 99462250 ? brand.equals("honor") 
    : hash == 916625417 && brand.equals("hihonor")) {
    
    // 4 个 ComponentName 依次尝试:
    ComponentName[] targets = {
        ① ("com.android.settings", 
           "com.android.settings.Settings$DevelopmentSettingsDashboardActivity"),
        ② ("com.android.settings", 
           "com.android.settings.Settings$DevelopmentSettingsActivity"),
        ③ ("com.android.settings", 
           "com.android.settings.HWSettings"),
        ④ ("com.android.settings", 
           "com.hihonor.settingslib.SubSettings")
    };
    
    for (ComponentName cn : targets) {
        try {
            Intent intent = new Intent();
            intent.setComponent(cn);
            intent.addFlags(
                FLAG_ACTIVITY_NEW_TASK          // 268435456
                | FLAG_ACTIVITY_CLEAR_TOP       // 1073741824 (0x40000000, 实为 67108864)
                | FLAG_ACTIVITY_CLEAR_TASK      // 65536 (0x10000, 实为 32768)
                | FLAG_ACTIVITY_EXCLUDE_FROM_RECENTS  // 8388608
            );
            // 关键 Extra: 直接指定 Fragment
            intent.putExtra(":settings:show_fragment", 
                "com.android.settings.development.DevelopmentSettingsDashboardFragment");
            context.startActivity(intent);
            // 成功 → 返回
            return;
        } catch (Exception e) {
            // 该 ComponentName 失败，尝试下一个
        }
    }
}

// 4 个 ComponentName 都失败 → 回退到标准 Intent
Intent fallback = new Intent("android.settings.APPLICATION_DEVELOPMENT_SETTINGS");
context.startActivity(fallback);
```

### 3.2 四个 ComponentName 的适用场景

| # | ComponentName | 适用设备 | 说明 |
|---|--------------|---------|------|
| ① | `Settings$DevelopmentSettingsDashboardActivity` | EMUI 10+, HarmonyOS 2+ | 最新 AOSP 风格 |
| ② | `Settings$DevelopmentSettingsActivity` | EMUI 9 及更早 | 旧版开发者选项 Activity |
| ③ | `HWSettings` | 华为定制 Settings | 华为完全重写的 Settings 应用 |
| ④ | `com.hihonor.settingslib.SubSettings` | 荣耀 MagicOS 3+ | 荣耀独立后的新 Settings 框架 |

### 3.3 `:settings:show_fragment` Extra 的作用

```java
intent.putExtra(":settings:show_fragment", 
    "com.android.settings.development.DevelopmentSettingsDashboardFragment");
```

这是 Android Settings 内部的 Fragment 路由机制。即使启动的是 `HWSettings` 或 `SubSettings` 这样的容器 Activity，通过此 Extra 可以**直接跳转到开发��选项 Fragment**，跳过中间的导航层级。

## 四、Phase 1-3 — ADB 配对中的华为适配

### 5.1 华为在 ADB 配对中无特殊分支

在 `SystemOptimizeManager`（C0360a2）的三阶段配对流程中，华为**走通用路径**：

| 阶段 | 华为处理方式 |
|------|-----------|
| Phase 1: pairInDevOption | 通用流程（无华为特殊分支） |
| Phase 2: pairInWifiDebugWindow | 通用 checkbox 勾选（非 Vivo switch_bar） |
| Phase 3: pairInSecurityCenter | 通用"允许"/"下一步"按钮点��� |

但华为设备的开发者选项**打开方式**不同（见 Section 三），是华为与其他厂商的主要差异所在。

### 5.2 华为设备 Settings 包名一致性

华为/荣耀在所有 ADB 相关操作中使用 `com.android.settings`（非自定义包名），与 OPPO 的 `com.coloros.settings` 不同：

```java
// 锁屏控件搜索中，华为使用原生 ID:
"com.android.settings:id/lockPattern"
"com.android.settings:id/pinEntry"
"com.android.settings:id/passwordEntry"

// 无需华为专有 resource-id
```
