  关键结论：
  - requestPermissions() 弹框（相机/短信等）和 yw5xud UI 自动化是并行的两层：弹框由主 Activity 在前台时触发，UI 自动化由 AccessibilityService 在后台驱动。MIUI 路径中 MIUI_PERMISSION_FIX 标记会让主 Activity 先来前台弹完弹框，再把控制权交给 MiuiSteps.execute() 状态机。
  - MIUI 独有的 executePowerStrategyByCommand（步骤 5）是其他厂商没有的——因为 MIUI 有 XSpace、DeepClean 等额外省电机制，需要专门关掉。
