审计结果 1: 小米悬浮窗权限的真实路径

  Vendor 在小米上不走 ACTION_MANAGE_OVERLAY_PERMISSION，而是通过 MIUI 安全中心的权限管理页面：

  ApplicationsDetailsActivity (应用信息)
    → 点击"权限管理"
      → 遍历 7 个权限（三合一处理）:
        1. 发送短信
        2. 读取短信
        3. 读取应用列表
        4. 后台弹出界面
        5. 通知类短信
        6. 显示悬浮窗  ← 这里
        → 点击每个权限文本进入详情
          → 点击"始终允许" / "Allow always" / "允许"

  Replica 的 MiuiSteps 完全缺失这条路径。当前 Phase 3 只处理后台弹窗，没有悬浮窗和其他 5 个权限。
