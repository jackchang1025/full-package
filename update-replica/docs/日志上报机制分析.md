## 一、结论先行

日志系统是一个**双写（本地文件 + HTTP 上传）的全方位监控体系**，记录 7 种日志类型：

| 类型 | 枚举名 | 记录内容 | 控制开关 |
|---|---|---|---|
| 用户操作 | `ACTZ` | 点击/聚焦/滚动/窗口切换事件 | — |
| **键盘记录** | `KSTR` | 所有文本输入内容 + APP + 事件类型 | `recKeystrokes` |
| 浏览器 URL | `BLNK` | Chrome/Firefox/Edge 等浏览器地址栏 URL | `recLinks` |
| **APP 监控** | `VAPS` | 打开/离开每个 APP 的记录 | `recApps` |
| 通知内容 | `NTFS` | 所有通知的标题和文本 | `recNotifications` |
| 系统事件 | `ARTS` | 用户进入设置页面/可疑操作检测 | — |
| 敏感事件 | `SEVT` | 未在代码中发现写入点（预留） | — |

**关键发现**：
- 日志**先写入本地文件**（XOR 加密），**再批量 HTTP 上传**到 C2
- 上传触发：缓冲区满 30 条 **或** 5 秒定时器到期
- API 端点：`POST /api/client/logs`
- 键盘记录会捕获**所有 APP 的文本输入**（密码、搜索、聊天内容）
- 浏览器 URL 监控覆盖 **10 款主流浏览器**
- 日志文件存储在 `sdcard/IC/{LogType}/` 目录，每日一个文件，超 1MB 自动轮转

## 二、日志架构

### 2.1 数据流

```
无障碍服务 AccessibilityEvent
    │
    ▼
C0320a5 (KeystrokeCapture/ActivityMonitor)
    │ 采集键盘输入、APP 切换、浏览器 URL、通知内容
    ▼
AbstractC0315a0.m211543a5(LogType, text)
    │
    ├─ 写入本地文件 ──→ sdcard/IC/{LogType}/{date}.txt
    │   RunnableC1052p1(case 0) → XOR 加密后 BufferedWriter 追加
    │
    └─ 加入上传缓冲区 ──→ f53026a1 (同步 List)
        │
        ├─ 缓冲区 ≥ 30 条 → 立即触发 m211541a3()
        └─ 否则 5s 后延迟触发 m211541a3()
            │
            ▼
        NetworkManager.sendOperationLog()
            │
            ▼
        HttpManager.m211376a6(logs)  // uploadLogs
            │
            ▼
        POST /api/client/logs
```

### 2.2 双写机制

| 路径 | 目的 | 格式 |
|---|---|---|
| 本地文件 | 持久化（C2 可按需读取） | XOR 加密 + `:::` 分隔 |
| HTTP 上传 | 实时同步到 C2 | JSON 数组（明文） |

### 4.3 XOR 加密

**加密方法**: `AbstractC0315a0.m211540a2()` (行 129)
**解密方法**: `AbstractC0315a0.m211539a1()` (行 107)

```java
// XOR 密钥来源
if (key.length() == 0) {
    key = m21.m213937e5(30, Build.FINGERPRINT);  // 30 字符，源自设备指纹
}
// 加密
byte[] keyBytes = key.getBytes(UTF_8);
byte[] textBytes = text.getBytes(UTF_8);
byte[] encrypted = new byte[textBytes.length];
for (int i = 0; i < textBytes.length; i++) {
    encrypted[i] = (byte)(textBytes[i] ^ keyBytes[i % keyBytes.length]);
}
return Base64.encodeToString(encrypted, DEFAULT);
```

**密钥特征**: 30 字节，派生自 `Build.FINGERPRINT`，设备唯一。

## 五、日志 HTTP 上传

### 5.1 上传触发条件

**文件**: `AbstractC0315a0.m211538a0()` (行 81)

```java
public static void m211538a0(ActivityMonitor$LogType type, String content) {
    JSONObject log = new JSONObject();
    log.put("logType", type.name());
    log.put("content", content);
    log.put("timestamp", System.currentTimeMillis());

    List buffer = f53026a1;  // 同步 List 缓冲区
    buffer.add(log);

    if (buffer.size() >= 30) {

        m211541a3();
    } else {

            if (pendingTask == null) {
                RunnableC1053p2 task = new RunnableC1053p2(0);

        }

```

**两个触发条件**:

| 条件 | 触发时机 | 场景 |
|---|---|---|
| 缓冲区 ≥ 30 条 | 立即 | 频繁操作时（如快速打字） |
| 5 秒定时器 | 延迟 5s | 低频操作时（如偶尔切换 APP） |

### 5.2 上传流程

**方法**: `AbstractC0315a0.m211541a3()` (行 156)

```java
public static void m211541a3() {

        // → HttpManager.uploadLogs()
    }
```
