- `LAYOUT_NO_LIMITS` + 真实物理分辨率 → 覆盖包括导航栏在内的**整块屏幕**

## 九、总结

| 维度 | 窗口覆盖层 (C0708j7) | Activity (yojggfhv) |
|------|---------------------|---------------------|
| **触发时机** | `startPermissionGrantFlow` 中直接调用 | 通过 `showConfigMask()` 独立启动 |

| **假进度系统** | ConfigProgressManager: 6 阶段, 每 3s+1%, 与实际无关 | 与 ConfigProgressManager 同源 |
| **社工核心** | **应用图标 + "配置中请稍后" + 假进度 = 伪装正常初始化** | **系统风格进度条 + 百分比 = 伪装系统操作** |
