# Vendor 反编译代码可读性与二次开发评估 — 设计文档

> 日期: 2026-04-02
> 范围: 327 个业务文件 (com/guard/wallet/ + o/)，~57K 行
> 目标: 评估 vendor 反编译代码能否直接作为二次开发基础

## 1. 背景

Vendor APK 经 JADX 反编译后产出 327 个业务 Java 文件，分布在 `com/guard/wallet/`（294 文件）和 `o/`（33 文件）两个包下。代码存在不同程度的 ProGuard 混淆和反编译质量问题。

本评估旨在系统性地回答：**这些反编译代码能否直接用于二次开发（逆向修改/扩展），而非仅作为参考重写？**

## 2. 评估方法论

### 2.1 五维度评分体系

对每个文件从 5 个维度评分（0-10 分），加权计算综合分：

| 维度 | 权重 | 含义 | 0 分 | 10 分 |
|------|------|------|------|-------|
| 编译可行性 | 25% | 反编译代码能否编译通过 | 全是 goto/语法错误 | 可直接编译 |
| 命名可读性 | 25% | 标识符是否有意义 | 全部单字母混淆 | 全部语义化命名 |
| 控制流清晰度 | 20% | 代码结构是否可追踪 | goto 横行/极深嵌套 | 结构清晰 |
| 依赖可追踪性 | 15% | 对外部混淆类的依赖程度 | 调用链全是混淆类 | 依赖关系清晰 |
| 二次开发适宜度 | 15% | 文件大小、职责、修改风险 | 万行大文件/职责混乱 | 小文件/职责单一 |

### 2.2 四级分类

| 等级 | 综合分 | 含义 | 操作建议 |
|------|--------|------|----------|
| A 级 | 8-10 | 直接可用 | 可直接编译、阅读、修改 |
| B 级 | 5-7 | 需修复 | 消除 goto、重命名变量后可用 |
| C 级 | 2-4 | 需重写 | 逻辑可参考但代码不可直接用 |
| D 级 | 0-1 | 不可用 | 混淆度太高，逆向成本超过重写 |

## 3. 自动化指标采集

### 3.1 采集指标

| 指标 | 采集方式 | 映射维度 |
|------|----------|----------|
| 文件行数 | `wc -l` | 二次开发适宜度 |
| goto 数量 | `grep -c 'goto '` | 编译可行性 |
| JADX WARN/INFO 数量 | `grep -c 'JADX WARN\|JADX INFO'` | 编译可行性 |
| 混淆字段比例 | 正则 `f\d+[a-z]` 字段数 / 总字段数 | 命名可读性 |
| 单字母方法比例 | 单字母方法定义数 / 总方法数 | 命名可读性 |
| 最大嵌套深度 | 缩进层级分析 | 控制流清晰度 |
| 外部混淆依赖数 | 引用 `o.` 包 + 单字母类的次数 | 依赖可追踪性 |
| switch-case 数量 | `grep -c 'case '` | 控制流清晰度 |

### 3.2 评分阈值（编译可行性示例）

| goto 数 | JADX WARN 数 | 评分 |
|---------|-------------|------|
| 0 | 0 | 10 |
| 0 | 1-5 | 8 |
| 1-5 | any | 5 |
| 6-20 | any | 3 |
| >20 | any | 1 |

其他维度的阈值在脚本实现时类似制定。

### 3.3 脚本输出

CSV 格式，每行一个文件：

```
file_path,lines,goto_count,jadx_warn_count,obf_field_ratio,single_letter_method_ratio,max_nesting,obf_dep_count,switch_cases,dim1,dim2,dim3,dim4,dim5,total,grade
```

## 5. 实施流程

### Step 1: 自动化扫描
- 编写 bash 脚本扫描 327 个文件
- 采集 8 项指标
- 按阈值计算评分
- 输出 CSV + 统计摘要

### Step 2: 人工采样校准
- 从 A/B/C/D 各抽取 3-5 个文件
- AI 深度阅读代码验证自动评分
- 调整阈值（如有系统性偏差）
- 对关键文件做详细分析：
  - `server/b.java` (11,172 行，命令路由中枢)
  - `utils/g.java` (3,142 行，万能工具类)
  - `o/a0.java` (2,003 行，126 goto)
  - `a1/q.java` (1,134 行，被引用 301 次)

### Step 3: 撰写报告
- 基于量化数据 + 采样分析
- 按第 4 节结构撰写完整报告
- 重点输出第 5 章实施方案
