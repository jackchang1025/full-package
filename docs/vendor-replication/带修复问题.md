将POST body 解析的问题构建到一个文档中我们考虑再来完善

            final StringBuilder bodyBuilder = new StringBuilder();

            // 设置 DataCallback 消费 body 字节
            sink.setDataCallback((emitter, bb) -> {
                if (bb.remaining > 0) {
                    bodyBuilder.append(bb.h(StandardCharsets.UTF_8));
                    bb.k(); // 释放 buffer，重置 remaining
                }
            });

            // 设置 EndCallback，body 接收完成后解析并分发
            sink.setEndCallback(ex -> {
                String raw = bodyBuilder.toString();
                switch (self.d) {
                    case 2: self.f = new JSONObject(raw); break;
                    case 5: self.f = raw; break;
                    case 7: self.e = QueryParameterMap.parse(raw, "&", false, URI_DECODER); break;
                }
                if (cb.request instanceof HttpConnectionHandler) {
                    ((HttpConnectionHandler) cb.request).dispatchToHandler();
                }
            });
        }
    }

    关键点：
    - bb.k() 必须调用，否则 remaining 不归零，触发 mDataHandler failed to consume data 异常
    - setEndCallback 接受 ExceptionCallback（不是 CompletionCallback）
    - body 解析完成后手动调用 dispatchToHandler() 将请求分发到路由 Handler
