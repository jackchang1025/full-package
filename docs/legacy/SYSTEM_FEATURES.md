# 飞鹰管理系统 - 功能详解

> 本文档详细介绍飞鹰管理系统的核心功能、架构设计和商业模式。

---

## 📱 系统定位

飞鹰管理系统是一个 **Android 远程设备管理平台**（Remote Administration Tool），采用 B2B SaaS 模式运营。

**核心组件**：
- **管理员后台**：管理客户账号和系统配置
- **客户面板**：客户登录后管理自己的设备
- **APK 构建器**：为客户生成定制化的 Android 客户端应用
- **实时通信**：通过 WebSocket 与设备保持长连接

---

## 👨‍💼 一、管理员后台功能

### 1.1 账号管理

**入口文件**：`src/private/create.php` + `src/private/createacc.php`

| 功能 | 说明 | 实现方式 |
|------|------|----------|
| 创建账号 | 为客户创建登录账号 | POST `createacc.php?action=add` |
| 随机生成 | 自动生成用户名/邮箱/密码 | 前端 JavaScript |
| 账号续期 | 设置/延长账号有效期 | POST `createacc.php?action=renew` |
| 试用账号 | 支持 1-3 天试用期 | 前端选择 + 自动计算过期日期 |
| 权限分配 | 管理员 / 普通客户 | `authorty` 字段 |
| 修改密码 | 更新用户密码 | POST `createacc.php?action=update_password` |
| 修改邮箱 | 更新用户邮箱 | POST `createacc.php?action=update_email` |
| 删除账号 | 单个删除 | POST `createacc.php?action=delete` |
| 批量删除 | 多选删除 | 前端循环调用 delete |
| 备注管理 | 为账号添加备注 | 存储在 `remarks.json` |
| 隐藏账号 | 隐藏/显示账号 | POST `createacc.php?action=toggle_hide` |
| 账号搜索 | 按用户名/邮箱搜索 | GET `createacc.php?action=list&search=xxx` |

### 1.2 账号限制

- **默认限制**：最多 6 个账号
- **突破限制**：隐藏功能，快捷键 `Ctrl+Shift+A` 显示"不受限制添加"按钮

### 1.3 隐藏功能快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+U` | 显示"删除邮箱唯一索引"按钮 |
| `Ctrl+Shift+H` | 显示"隐藏账号"按钮 |
| `Ctrl+Shift+S` | 显示"显示隐藏账号"按钮 |
| `Ctrl+Shift+A` | 显示"不受限制添加"按钮 |

### 1.4 过期账号处理

**脚本文件**：`src/private/check_expired_accounts.php`

- 定时检查过期账号
- 自动生成随机密码替换原密码
- 记录操作日志到 `expired_accounts.log`
