## 🗂️ 一、核心文件组成

### 1.1 PHP 层文件

| 文件 | 作用 |
|------|------|
| `src/private/Eaod36921.php` | **构建 API 入口** - 接收请求、验证参数、调用构建函数 |

| `src/private/Eaod45071.php` | **自定义应用回调** - VB.NET 程序回调更新构建状态 |
| `src/private/Eaod90061.php` | **商店应用回调** - VB.NET 程序回调更新构建状态 |

| 文件 | 作用 |

## 📝 三、构建参数详解

### 3.1 参数传递方式

PHP 通过命令行参数调用 `EaodStarter.exe`，所有参数均经过 Base64 编码。

```php
$command = "EaodStarter.exe " . escapeshellarg("lunch") . " ";
foreach ($arguments as $arg) {
    $command .= escapeshellarg(base64_encode($arg)) . " ";
}
exec($command, $output, $return_var);
```

### 3.2 参数列表 (按顺序)

1. `appid`: 应用包名
2. `userid`: 用户ID
3. `clientname`: 客户端名称
4. `email`: 用户邮箱
5. `mainActivity`: 主Activity (商店应用)
6. `app_folder`: 应用文件夹 (商店应用)
7. `UserHost`: 服务器地址
8. `use_access`: 无障碍权限开关
9. `use_antkill`: 防杀进程开关
10. `use_atoprims`: 自动权限开关
11. `notifytitle`: 通知标题
12. `notifymsg`: 通知内容
13. `user_allprims`: 全部权限开关
14. `user_blackprims`: 黑名单权限开关
15. `buildtype`: 构建类型 (S/C)
16. `appname`: 应用名称
17. `appversion`: 版本号
18. `appicopath`: 图标路径
19. `appurl`: 应用链接
20. `logintitle`: 登录标题
21. `logindis`: 登录描述
22. `loginbtn`: 登录按钮
23. `lngshort`: 语言代码
24. `hiddenapp`: 隐藏应用开关
25. `noemulator`: 禁止模拟器开关
26. `installtype`: 安装类型
27. `hide_type`: 隐藏方式
28. `use_draw`: 悬浮窗权限
29. `open_access`: 打开无障碍
30. `descr_iption`: 应用描述
31. `diao_type`: 弹窗类型

## 🏗️ 四、两种构建类型

### 4.1 自定义构建 (Custom - Type C)

用户拥有完全的控制权：
- **图标**: 用户上传自定义 PNG 图标 (需 MD5 命名)
- **配置**: 包名、名称、版本、服务器地址、功能开关均由用户指定
- **模板**: 使用基础模板 `apkstub.zip`

### 4.2 商店构建 (Store - Type S)

基于预设模板快速构建：
- **模板来源**: 数据库 `store` 表 (app_id -> main_activity, app_folder)
- **参数**: 用户只需配置部分参数 (客户端名称、服务器地址、功能开关)
- **Activity**: 使用模板指定的 Activity 类名

## 🔧 五、VB.NET 构建程序工作原理 (推测)

`EaodStarter.exe` 和 `EaodWorker.exe` 是 Windows 应用程序，利用 `apktool` 实现 APK 的反编译和重打包。

### 5.1 工作步骤

1. **参数解析**: 解码 Base64 参数，生成配置对象。
2. **状态回调**: 向 PHP 发送 `onbuild` 状态。
3. **准备环境**: 解压 `apkstub.zip` 模板到临时目录。
4. **反编译**: 调用 `java -jar apktool.jar d` 反编译 APK。
5. **修改内容**:
   - 修改 `AndroidManifest.xml`: 替换包名、权限、Activity。
   - 替换资源: 覆盖 `res/drawable` 中的图标，更新 `res/values/strings.xml`。
   - 注入配置: 修改 `smali` 代码，植入服务器地址和功能开关。
6. **重打包**: 调用 `java -jar apktool.jar b` 重新打包为 APK。
7. **签名**: 使用签名工具对 APK 进行签名。
8. **保存**: 将最终 APK 移动到用户目录。
9. **完成回调**: 向 PHP 发送 `finished` 或 `failed` 状态。

---

## 📡 六、状态回调机制

VB.NET 程序通过 HTTP POST 请求向 PHP 汇报进度，接口仅允许本地访问 (127.0.0.1)。

### 6.1 接口地址
- 自定义应用: `src/private/Eaod45071.php`
- 商店应用: `src/private/Eaod90061.php`

### 6.2 状态流转
`onbuild` (开始) -> `finished` (成功) 或 `failed` (失败)
